# RQ-022 — Foundational SLA mechanisms and competing instructional theories

**Status:** initial meta-foundation synthesis complete  
**Date:** 2026-08-27  
**Claims:** `CLM-FND-001`–`CLM-FND-019`  
**Evidence digest:** `06-evidence/RQ-022-source-digest.md`

## 1. Research question

> Which learning mechanisms and instructional theories have the strongest converging evidence for adult instructed L2 development, which predictions conflict, and what does each imply for Vietnamese near-A0 self-study?

The objective is not to crown one named theory.

The objective is to prevent Nếp from doing this:

```text
find plausible theory
→ turn theory into method
→ build product
```

Instead:

```text
competing theories
+ comparative/meta-analytic evidence
+ outcome/measurement differences
+ learner/task moderators
→ constrained instructional synthesis
```

## 2. Main conclusion

### No single exclusive mechanism survives the evidence as a complete method

The strongest conclusion from RQ-022 is negative but useful:

```text
input alone
≠ complete method

explicit rules alone
≠ complete method

output alone
≠ complete method

conversation alone
≠ complete method

frequency alone
≠ complete method

practice alone
≠ complete method
```

The evidence instead supports **complementary learning conditions whose value depends on the target outcome**.

A compact formulation is:

```text
MEANING
  ↓
FORM ↔ MEANING/FUNCTION ACCESS
  ↓
RETRIEVAL / PERFORMANCE FOR THE TARGET SKILL
  ↓
FEEDBACK / REPAIR WHEN NEEDED
  ↓
REPEATED + VARIED PRACTICE
  ↓
MORE MEANINGFUL EXPOSURE / INTERACTION
  ↓
INCREASING EFFICIENCY + GENERALIZATION
```

This is not a lesson template and not yet `Nếp Method`.

## 3. What the main theory/evidence families contribute

### 3.1 Meaningful/comprehensible input

Instruction cannot develop listening/reading comprehension or language representations without substantial input.

Incidental vocabulary evidence confirms that learners do acquire unknown language while focusing on meaning.

But pickup from one period of exposure is limited, especially for a beginner with a small vocabulary.

Therefore:

```text
input is necessary
```

but current evidence does not justify:

```text
input alone is sufficient or optimally efficient
```

for every target.

### 3.2 Input Processing / Processing Instruction

Processing Instruction provides strong evidence that instruction can target **how learners map forms to meaning while comprehending**.

This is especially relevant when learners systematically rely on a misleading cue or fail to process a meaningful grammatical cue.

Strong contribution:

```text
make correct form ↔ meaning processing necessary
```

Not supported as universal extension:

```text
therefore production practice is unnecessary
```

Comparative meta-analysis shows production practice retains a distinct role for productive outcomes.

### 3.3 Output and production practice

Production does more than display knowledge when the target capability itself requires production.

It can require learners to:

- retrieve form;
- formulate under constraints;
- notice gaps;
- test hypotheses;
- integrate lexical/grammatical resources;
- build faster access through practice.

Comparative evidence is especially important here: production-based instruction can be stronger on delayed productive measures even when input-based work is stronger for receptive processing.

Therefore:

```text
if target = speaking/writing performance
production practice belongs in the learning path
```

The exact point at which it begins remains conditional, not a universal waiting threshold.

### 3.4 Interaction Approach

Interaction is not merely “more speaking.”

Its value comes from contingent events such as:

```text
message problem
→ request / negotiation
→ modified input
→ feedback
→ noticing
→ modified output / repair
```

Therefore an AI conversation partner that produces many turns is not automatically an interaction intervention of equal quality.

For interactive capability, the product eventually needs tasks where:

- the partner response depends on learner meaning;
- misunderstanding can occur;
- repair has communicative consequence;
- the learner must process unexpected continuation.

### 3.5 Form-focused / explicit instruction

The evidence is strong enough to reject an ideology that explicit instruction is inherently harmful or useless.

Focused instruction and explicit treatment often accelerate targeted L2 learning.

But three cautions are essential:

1. many outcome measures disproportionately capture explicitly accessible knowledge;
2. short treatments can favor explicit instruction because implicit learning generally needs larger exposure;
3. knowledge about a form is not automatically spontaneous ability to use the form.

Therefore the useful product question is not:

```text
explicit or implicit?
```

It is:

```text
what problem does explicit information solve here?
```

Candidate legitimate uses:

- clarifying a hard form–meaning contrast;
- overcoming L1-tuned attention;
- providing a compact pattern after meaningful exemplars;
- enabling deliberate practice;
- making feedback interpretable.

Bad default:

```text
rule presentation
→ rule quiz
→ mark grammar mastered
```

### 3.6 Skill Acquisition Theory

SAT contributes a powerful distinction:

```text
knowledge ABOUT language
≠
skill USING language
```

It also provides an explanation for why deliberate practice can turn effortful performance into more efficient performance.

Recent direct evidence supports a declarative/procedural/automatic trajectory under a specific explicit miniature-language learning condition.

This strengthens SAT as a candidate explanatory framework.

But the directness limit matters:

```text
three stages in controlled Mini-Nihongo comprehension
≠
proof that every natural English skill must be taught rule-first
```

Nếp should inherit the **knowledge-versus-skill distinction and importance of high-quality practice**, not blindly import a universal three-stage lesson sequence.

### 3.7 Usage-based / construction approaches

Usage-based accounts contribute a different but highly compatible warning:

```text
language is not just rules + words
```

Learners develop networks of form–meaning/function constructions from experienced exemplars.

Important variables include:

- frequency;
- contingency;
- salience;
- prototypicality;
- exemplar variation;
- learned attention from L1.

This supports:

```text
teach useful language in meaningful patterns
+ expose learners to multiple exemplars
+ gradually support abstraction/recombination
```

It does **not** support:

```text
sort corpus by frequency
→ teach in that order
```

Frequency is one determinant among several.

### 3.8 Attention / noticing

RQ-022 distinguishes two statements that are too often collapsed:

```text
attention matters
```

and

```text
perceptual enhancement is enough
```

The first has substantial theoretical/empirical support.

The second does not.

Textual enhancement has modest average effects and may compete with meaning processing.

Therefore Nếp should prefer tasks in which a target cue is **functionally needed to solve a meaning problem** rather than simply coloring/bolding it.

### 3.9 Intentional and incidental learning

Vocabulary research gives one of the clearest examples of complementarity.

Intentional learning:

```text
fast initial acquisition
+ efficient target coverage
− substantial later forgetting
− limited contextual/generalization evidence by itself
```

Incidental meaning-focused learning:

```text
contextual experience
+ real incidental pickup
+ broad exposure benefits
− low pickup proportion per unknown word/exposure period
− depends heavily on proficiency/exposure/materials
```

A near-zero learner therefore likely needs **both**:

```text
efficient deliberate establishment
+
rich repeated contextual encounters/use
```

The optimal ratio is not established here.

### 3.10 Sociocultural Theory / mediation

SCT adds something the existing independent-evidence framework was at risk of under-valuing:

```text
what learner can do alone
```

and

```text
what learner can do / learn under contingent mediation
```

are different developmental observations.

This leads to a useful future learner model distinction:

```text
CURRENT INDEPENDENT PERFORMANCE
        +
RESPONSIVENESS TO MEDIATION
```

Assistance should not be re-labeled independent mastery.

But assistance can still reveal:

- where the learner is close to success;
- what type of cue resolves the problem;
- how much support is required;
- what instruction should happen next.

Assessment-validity implications are deferred to RQ-024.

## 4. Theoretical disagreements that remain real

RQ-022 does not pretend all theories are secretly identical.

### 4.1 What is the mental representation of L2 knowledge?

Skill Acquisition Theory often describes declarative knowledge becoming proceduralized through practice.

Usage-based approaches emphasize exemplar-driven construction learning and emergent abstraction.

SCT conceptualizes development through socially/culturally mediated activity and internalization.

These are not interchangeable ontologies.

For the product, however, a method does not need to settle every cognitive ontology before using converging instructional evidence.

Where competing theories produce different product predictions, the contradiction must remain open or become an experiment.

### 4.2 What counts as implicit knowledge?

Explicit/implicit knowledge is difficult to measure cleanly.

Timed tests, elicited imitation, reaction-time tasks and spontaneous production each contain different contaminating processes.

Therefore RQ-022 refuses to make:

```text
explicit instruction → implicit acquisition
```

or

```text
implicit exposure → implicit acquisition
```

from intervention labels alone.

RQ-024 must handle inference validity.

### 4.3 Is supported performance evidence of ability?

Psychometric/independent-performance traditions and dynamic-assessment traditions ask different questions.

Nếp should not force them into a single scalar mastery score.

Candidate resolution:

```text
independent evidence answers:
“What can learner currently do under these unassisted conditions?”

mediated evidence answers:
“What assistance changes performance and what may be developing?”
```

Both can drive teaching decisions while remaining semantically distinct.

## 5. Provisional instructional constraints from RQ-022

These are **constraints**, not final principles/PRN IDs yet.

### Constraint A — meaning first, not meaning only

New language should normally be attached to a meaningful communicative interpretation/use.

But difficult cues may require deliberate attention or explanation.

### Constraint B — input rich, not input only

Learners need substantial meaningful input.

When the desired capability is production, they also need retrieval/production practice.

### Constraint C — explicit support must have a job

Do not teach rules because a syllabus has a grammar box.

Use explicit support when there is a documented processing/knowledge problem it can plausibly solve.

### Constraint D — practice must match the target skill

```text
type answer
≠ speaking practice

recognize meaning
≠ production practice

repeat trained sentence
≠ flexible transfer
```

Practice should increasingly resemble the processing requirements of the target capability without jumping beyond learner readiness.

### Constraint E — feedback should create learning/repair, not just judgment

Feedback is potentially powerful but policy depends on RQ-025.

### Constraint F — exemplars before premature abstraction, but abstraction is not forbidden

Rich useful exemplars support construction learning.

A concise generalization may become useful when it helps learners process/recombine the exemplars.

### Constraint G — deliberate + incidental are complements

Beginners should not be forced to wait for accidental pickup of every high-value item.

Deliberately established knowledge should later receive varied contextual encounters.

### Constraint H — support response and independent performance are separate evidence

Scaffolding may be valuable and diagnostic.

Never convert a supported success retroactively into independent mastery.

## 6. Candidate generic learning cycle after RQ-022

The old foundational loop remains partly plausible but is now revised conceptually:

```text
TARGET MEANING / CAPABILITY
        ↓
UNDERSTANDABLE EXEMPLAR(S)
        ↓
FORM ↔ MEANING/FUNCTION PROCESSING
        ↓
OPTIONAL EXPLICIT HELP
only if it solves a real barrier
        ↓
RETRIEVAL / PERFORMANCE
in the target modality
        ↓
CONTINGENT FEEDBACK / SELF-REPAIR
        ↓
REPEATED + VARIED PRACTICE
        ↓
MORE CONTEXTUAL INPUT / INTERACTION
        ↓
INCREASINGLY INDEPENDENT + EFFICIENT PERFORMANCE
        ↓
DELAYED / CHANGED-CONTEXT EVALUATION
```

Crucially:

- not every target needs every box in every session;
- the loop can span days/weeks;
- some targets may be established primarily through exposure;
- some processing problems may need explicit intervention;
- interactive abilities require real contingency;
- productive ability requires actual production.

## 7. What RQ-022 changes from earlier Nếp thinking

### Earlier risk

```text
research individual features
→ integrate them all
→ call architecture comprehensive
```

### New model

```text
identify target capability
→ identify learning/processing bottleneck
→ choose evidence-backed mechanism for that bottleneck/outcome
→ preserve modality/construct distinctions
→ revisit under different context/time
```

This is a more defensible foundation for later adaptive instruction.

## 9. Falsification / revision triggers

This synthesis should be revised if later high-quality evidence shows, for the relevant constructs/populations, that:

- one purportedly complementary condition consistently adds no learning benefit once exposure/time is controlled;
- explicit support reliably harms long-term spontaneous outcomes under conditions Nếp would use;
- production practice does not improve productive generalization beyond well-matched comprehension/input practice;
- interaction gains are fully explained by extra input/time rather than contingent interaction mechanisms;
- mediated-responsiveness measures have no useful predictive/diagnostic value for learning decisions;
- target-population data contradict the assumed near-A0 applicability of these mechanisms.

## 10. RQ-022 decision

Mark foundational SLA theory coverage as **initial synthesis complete, not closed forever**.

The result is not a finished method.

It is a constraint on future method synthesis:

> **Nếp must be outcome- and mechanism-sensitive rather than loyal to one branded teaching method. Meaningful input, form–meaning processing, deliberate support, productive practice, interaction, feedback, contextual exposure and automatization each have evidence-backed roles, but their value changes with the target capability and conditions.**
