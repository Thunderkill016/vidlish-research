# Effective learning system — current synthesis

The existing Vidlish dossier supports a product that combines multiple mechanisms rather than betting on one method.

## Current synthesis

A useful beginner system should progressively combine:

- comprehensible, bounded input;
- attention to form/sound when useful;
- vocabulary/chunks embedded in meaningful contexts;
- retrieval with the answer hidden;
- spacing across sessions;
- controlled then guided output;
- changed-context use;
- listening perception and segmentation work;
- intelligibility-oriented pronunciation support;
- delayed evidence of retention;
- later, graded and authentic sources when input is usable.

## What this does not prove

It does not prove:

- one exact lesson template is optimal;
- one exact SRS interval is optimal;
- the target user will return;
- 300 or 1,000 words is a scientifically exact readiness threshold;
- video is necessary for beginners;
- AI feedback improves learning enough to justify its cost/risk.

Those are product/curriculum decisions requiring validation.
