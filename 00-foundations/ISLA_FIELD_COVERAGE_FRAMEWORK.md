# ISLA field coverage framework for Nếp

**Status:** meta-foundation / coverage control  
**Date:** 2026-08-27  
**Purpose:** prevent feature-by-feature research from being mistaken for a comprehensive theory of how Nếp should teach English.

## 1. Why this file exists

The repository now contains detailed research cycles for many product questions, but its foundational SLA layer was seeded before those cycles and was never expanded into a systematic comparison of the main theories, mechanisms, learner differences, curriculum-design traditions and assessment-validity traditions in second-language learning.

That creates a structural risk:

```text
strong research on many local questions
        ≠
complete evidence base for one global teaching method
```

Nếp therefore needs a field-coverage map before a final `Nếp Method` can be accepted.

This framework is a **coverage scaffold**, not a claim that the listed schools are equally correct or mutually exclusive. The point is to force the research program to ask what each perspective predicts, what evidence supports it, where it conflicts with alternatives, and what remains useful for the target learner.

## 2. Target decision

The final research program must be able to answer:

> For Vietnamese-speaking adults beginning near zero, what combination and sequencing of learning conditions is best supported for developing durable, flexible everyday/work English under realistic self-study constraints?

The target is not a universally optimal method for all learners.

## 3. Coverage domains

### F1 — Nature of L2 knowledge and acquisition

Questions:

- What kinds of L2 knowledge should instruction aim to develop?
- How should explicit/declarative knowledge be distinguished from proceduralized/implicit language ability?
- Which changes are acquisition, which are task-specific performance, and which are test learning?
- What can instruction accelerate or improve, and what remains constrained by exposure/development?

Required perspectives/evidence families:

- instructed SLA syntheses;
- explicit vs implicit knowledge/learning;
- intentional vs incidental learning;
- developmental constraints;
- declarative/procedural knowledge and automatization.

### F2 — Input, processing, attention and noticing

Questions:

- What makes input usable rather than merely present?
- What roles do comprehension, lexical coverage, attention, noticing and depth of processing play?
- When is structured input useful?
- How does L1 affect online processing?

Required perspectives/evidence families:

- Input Processing / Processing Instruction;
- comprehensible input research;
- noticing/attention;
- input enhancement;
- depth of processing;
- multimodal and aural processing.

### F3 — Output, practice and skill development

Questions:

- What does production contribute beyond comprehension?
- What practice produces proceduralization/automaticity rather than memorized item speed?
- What amount and kind of repetition is useful?
- When should production be controlled, guided or freer?

Required perspectives/evidence families:

- Output Hypothesis and production research;
- Skill Acquisition Theory;
- retrieval/practice effects;
- task repetition and variability;
- fluency/automaticity.

### F4 — Interaction, negotiation and socially mediated learning

Questions:

- What does interaction add beyond input and isolated output?
- What roles do negotiation for meaning, repair, feedback and contingent responses play?
- What kinds of scaffolding help development without replacing performance?

Required perspectives/evidence families:

- Interaction Approach;
- interactional feedback;
- Sociocultural Theory;
- scaffolding / ZPD / dynamic assessment;
- peer/human/computer-mediated interaction.

### F5 — Form, constructions and corrective feedback

Questions:

- When and how should attention be drawn to grammar, morphology, phonology and lexis?
- When is explicit explanation useful?
- How do focus on form, focus on forms and meaning-first approaches compare?
- Which feedback type, timing and intensity help which learner/feature/task?

Required perspectives/evidence families:

- form-focused instruction;
- explicit vs implicit instruction;
- Processing Instruction;
- usage-based / construction approaches;
- oral and written corrective feedback;
- recasts, prompts, metalinguistic feedback, self-repair;
- focused vs unfocused and immediate vs delayed feedback.

### F6 — Language content: what English is worth learning first?

Questions:

- Which words, chunks, constructions, functions and pragmatic routines have highest value for target needs?
- How should corpus frequency, range, dispersion, lexical coverage, formulaicity, learnability and target-situation usefulness be combined?
- What should be selected because it is common, because it enables high-value tasks, or because it is a prerequisite?

Required perspectives/evidence families:

- corpus-informed curriculum design;
- high-frequency vocabulary;
- beginner lexical lists;
- formulaic sequences / multiword units;
- construction frequency;
- spoken vs written registers;
- target-situation needs analysis.

### F7 — Curriculum, tasks and materials

Questions:

- What real-world capabilities should define the syllabus?
- What counts as a pedagogical task?
- How should difficulty and complexity be sequenced?
- How should graded, controlled and authentic materials be combined?
- How should the curriculum balance meaning-focused input/output, deliberate learning and fluency?

Required perspectives/evidence families:

- needs analysis and task-based needs analysis;
- Communicative Language Teaching;
- Task-Based Language Teaching;
- task-supported instruction;
- Four Strands;
- graded/extensive input;
- corpus/materials evaluation;
- curriculum evaluation and iteration.

### F8 — Skills and modalities

Must cover each skill as a real construct, not merely a feature list:

- listening: perception, lexical access, segmentation, comprehension, discourse;
- speaking: conceptualization, formulation, articulation, fluency, interaction;
- reading: word recognition, lexical/syntactic processing, discourse comprehension, fluency;
- writing: idea generation, formulation, text construction, revision, genre;
- pronunciation: intelligibility, comprehensibility, segmental/suprasegmental priorities;
- interaction/pragmatics: turn-taking, repair, appropriateness, contingency.

Cross-modal transfer must be researched rather than assumed.

### F9 — Vocabulary and formulaic language

Questions beyond `does the learner know this item?`:

- which items first;
- depth vs breadth;
- receptive vs productive knowledge;
- collocation and phrase knowledge;
- incidental vs deliberate learning;
- encounters/repetitions;
- lexical coverage and comprehension;
- recycling across contexts and modalities.

### F10 — Individual differences, affect and self-regulation

Questions:

- Which learner differences materially change instruction?
- What should be adapted and what should not be over-personalized?
- How do anxiety, self-efficacy and willingness to communicate change performance and learning?
- Which self-regulation supports improve outcomes rather than merely engagement?

Required evidence families:

- language aptitude;
- working memory / cognitive resources;
- anxiety;
- motivation, including self-determination perspectives;
- self-efficacy;
- willingness to communicate;
- self-regulated learning / metacognition;
- prior education/literacy;
- accessibility and neurodiversity where evidence permits.

### F11 — L1, multilingualism and Vietnamese learners

Questions:

- When does Vietnamese help comprehension, noticing or explanation?
- Which L1 processing/phonological/lexicogrammatical patterns are useful priors?
- How should population-level tendencies be prevented from becoming stereotypes?
- How quickly should direct learner evidence override an L1 prior?

This includes but is not limited to pronunciation.

### F12 — Assessment, diagnosis and inference validity

Questions:

- What exactly is each task intended to measure?
- What observations justify what inference about the learner?
- How reliable/generalizable is that inference across tasks, contexts and scorers?
- What support invalidates an independent-performance claim?
- How should learning-oriented/formative assessment differ from summative proficiency claims?

Required perspectives/evidence families:

- language assessment validity;
- reliability/generalizability;
- Evidence-Centered Design or equivalent task/evidence/proficiency modeling;
- diagnostic assessment;
- formative / learning-oriented assessment;
- performance/task-based assessment;
- rater/scorer reliability;
- consequences and use of classifications.

### F13 — Retention, transfer and longitudinal development

Questions:

- What schedules sustain learning efficiently?
- What counts as transfer rather than repetition?
- Which near/far transfer expectations are realistic?
- How should learning be evaluated weeks/months later?

This domain includes spacing/retrieval but must also consider curriculum-level longitudinal growth.

### F14 — Technology-mediated learning

Questions:

- When do AI, ASR, TTS, captions, adaptive algorithms or mobile affordances improve learning?
- Which effects are technology effects versus pedagogical effects?
- Which automated judgments are valid for which construct/population/task?
- What happens under model/provider drift?

Technology does not become a learning theory.

### F15 — Motivation, habit and sustained participation

Questions:

- What makes learners continue meaningful practice?
- How should return behavior interact with autonomy, competence, anxiety and self-regulation?
- Which engagement mechanics distort the learning objective?

Product retention is a subset of this domain, not a replacement for L2 motivation research.

### F16 — Research methodology and evidence synthesis

Every research claim must consider:

- study design and risk of bias;
- outcome construct and measurement sensitivity;
- immediate vs delayed outcomes;
- trained-item vs novel/transfer outcomes;
- sample/population directness;
- treatment fidelity;
- publication bias / meta-analytic heterogeneity when available;
- replication/convergence;
- competing explanations.

## 4. Required evidence axes

The existing `A–E` label is useful as a compact confidence signal but is not enough for the final method synthesis. Future meta-foundation claims should separately record at least:

```text
methodological_quality
population_directness
construct_directness
replication_consistency
transfer_to_product_context
```

Suggested bands:

```text
high / moderate / low / unknown
```

These axes must not be collapsed mechanically into one number.

## 5. Contradiction handling

A mature research program must represent disagreement explicitly.

For each contested instructional decision record:

```text
question
→ competing positions
→ evidence supporting each
→ outcome constructs used
→ moderators / boundary conditions
→ current synthesis
→ residual uncertainty
→ what result would change the synthesis
```

Examples requiring explicit controversy synthesis:

1. comprehensible/input-first vs production/practice emphasis;
2. explicit vs implicit instruction;
3. intentional vs incidental learning;
4. focus on form vs focus on forms;
5. processing instruction vs production-based practice;
6. explicit corrective feedback vs recasts/implicit feedback;
7. task-based vs task-supported / structured instruction;
8. formulaic chunks vs early abstraction/generative constructions;
9. graded/controlled input vs authentic input;
10. strategic L1 use vs L2-only instruction;
11. repeated stabilization vs contextual variability for fluency/transfer;
12. psychometric independent assessment vs mediated/dynamic assessment.

## 6. Nếp Method acceptance gate

Do **not** label a system `Nếp Method` as accepted until all of the following are true:

### Gate A — field coverage

Every F1–F16 domain is either:

- researched to a justified depth; or
- explicitly declared out of scope with rationale.

### Gate B — competing theories

Major competing explanations are compared rather than silently blended.

### Gate C — content/needs validity

The first capability and language-content set is grounded in target-user needs plus corpus/usage evidence, not intuition alone.

### Gate D — assessment validity

Core learner-state inferences have explicit construct/task/evidence arguments and validation plans.

### Gate E — target-population directness

Where evidence is indirect, the method states that explicitly and specifies target-population validation.

### Gate F — falsifiability

Every nontrivial product-specific rule has a condition under which it would be revised or rejected.

### Gate G — learner outcome evidence

Before claiming efficacy, real target learners must demonstrate delayed and changed-context gains using measures that are not simply the trained tasks.

## 7. Current status

As of 2026-08-27:

- Nếp has substantial **feature-level** evidence coverage.
- It does **not yet** satisfy the field-coverage gate above.
- The current integrated system synthesis and Nếp v1 product documents are useful hypotheses/handoff drafts, but they are **pre-meta-foundation and provisional**.
- No existing product implementation is evidence that the method is effective.

The next research phase is to close the highest-leverage foundation gaps before producing `SYN-METHOD-001`.
