# EXP-014 — From supported production to independent new writing

## Primary question

Which early writing policy produces the best **delayed independent new-task writing gain per learning minute** for Vietnamese near-A0 learners without creating persistent dependence on models, translation or AI rewriting?

## Population

Vietnamese-speaking Nếp learners near A0/A1 who:
- can read/write Vietnamese;
- can type or otherwise enter short text;
- have learned the target English meanings, vocabulary/chunks and constructions through earlier Nếp work;
- have enough independent evidence to make the target writing task learnable.

Stratify by:
- target vocabulary evidence;
- target construction evidence;
- baseline independent sentence production;
- typing/input fluency;
- prior translation/model/AI reliance;
- baseline writing anxiety/effort if measured.

## Core experimental rule

Every condition must capture the learner's own output **before** strong corrective/model/AI support is shown.

Final evaluation must use new tasks without strong support.

## Conditions

### A — controlled form practice

```text
sentence reconstruction
fill gaps
translation/select answer
copy/rewrite target forms
```

Matched for target vocabulary/constructions and approximate learning time.

Purpose:
baseline against a common controlled-writing approach.

### B — adaptive guided writing + bounded feedback

```text
communicative situation
→ independent/guided attempt at current support level
→ capture evidence
→ prioritized feedback
→ self-repair or bounded direct model
→ new-content writing
```

No full comparator/model unless required by the feedback policy.

### C — condition B + post-draft comparator models

```text
first draft
→ capture evidence
→ targeted feedback
→ show 1–2 compact comparator/model examples
→ learner notices difference
→ hide comparator
→ revision
→ new-content writing
```

Models are unavailable on final independent probes.

### D — condition B + constrained AI/AWE feedback

```text
first draft
→ capture evidence
→ AI/AWE may diagnose + hint + bounded alternative
→ no full rewrite before learner repair
→ revision
→ new-content writing
```

Any AI-generated wording is logged. Full-sentence or full-message rewrites, if experimentally allowed in a subcondition, must be marked high-support and cannot contribute directly to independent mastery.

## Optional D2 red-team subcondition

If ethically/productively useful, test a deliberately stronger AI assistance policy:

```text
first draft
→ AI rewrites the message
→ learner reviews
```

This is not expected to be the preferred pedagogy. Its purpose is to measure whether polished immediate output creates dependence or weak transfer relative to bounded feedback.

Do not deploy D2 broadly without clear labeling and evidence controls.

## Writing task ladder

Use a target family across stages:

```text
W1 guided sentence
W2 changed-content independent sentence
W3 2–4 proposition micro-message
W4 same functional genre / new content
```

Example family:

```text
request food/drink
→ request an object
→ request help
→ short message combining request + time/place
```

Another family:

```text
identity / location
→ arrival update
→ delay/apology update
→ work/delivery status message
```

## Materials and task matching

For each task record:
- communicative goal;
- required meanings;
- vocabulary prerequisites;
- construction prerequisites;
- number of propositions;
- genre/function;
- content novelty;
- lexical novelty;
- construction novelty;
- expected typing length;
- allowed support.

Do not use global CEFR labels as the only task-difficulty control.

## Immediate evidence

Before feedback:
- message fulfillment;
- required meaning coverage;
- independent lexical retrieval;
- target construction use;
- organization at the task's stage;
- language accuracy;
- planning time;
- writing time;
- support opened before submission.

After feedback:
- issue understood;
- repair attempted;
- repair correctness;
- revision quality;
- feedback accepted/rejected;
- learner-generated vs system-generated wording.

## Immediate new-task transfer

After feedback/revision, present a **different content task** requiring some of the same target language.

No access to:
- previous draft;
- comparator/model;
- AI rewrite;
- persistent translation.

A bounded hint may be available only after independent first-pass evidence is captured.

## Primary delayed outcome

After delay, use unseen writing tasks matched to target readiness:

```text
new content
no prior draft
no model
no AI rewrite
no persistent translation
self-paced within a reasonable product window
```

Measure separately:
- communicative success;
- required meaning coverage;
- lexical retrieval;
- construction use;
- organization;
- linguistic accuracy;
- support requested after first attempt;
- writing time.

Primary efficiency metric:

```text
delayed independent new-task writing gain
────────────────────────────────────────
learning minutes
```

Do not collapse dimensions until their construct validity and weighting are justified.

## Revision-versus-learning analysis

For every treatment calculate:

```text
same_text_revision_gain
new_task_immediate_gain
delayed_new_task_gain
```

Key diagnostic:

```text
large revision gain
+ weak new-task gain
= feedback helped the text more than the learner's transferable writing
```

## AI-dependence analysis

For AI conditions compare:

```text
quality while AI support available
vs
quality on next unsupported task
vs
delayed unsupported task
```

Track:
- number of AI hints;
- number of system-supplied words;
- full-sentence/full-message exposure;
- acceptance rate;
- amount learner changes system wording;
- repeated request for AI on later tasks.

Potential dependence signal:

```text
assisted final-draft quality ↑
while unsupported transfer ↔ or ↓
```

## Comparator/model analysis

For condition C track:
- features noticed;
- lexical/construction/content/organization category;
- copied vs adapted wording;
- subsequent use when model unavailable;
- delayed transfer.

A learner reproducing a model nearly verbatim on the same task is not sufficient transfer evidence.

## Feedback-strength analysis

Log each feedback event as:

```text
location cue
retrieval cue
metalinguistic cue
bounded example
direct correction
comparator exposure
AI alternative
AI rewrite
```

Test whether stronger feedback is beneficial when learner evidence is weak and whether weaker retrieval cues work better when evidence is already available.

Do not assume one universal ordering in advance.

## Feedback-scope analysis

Randomize or adapt within safe bounds:
- one high-value issue;
- small prioritized set;
- broader correction set.

Measure:
- repair success;
- cognitive effort;
- abandoned revisions;
- new-task transfer;
- delayed accuracy.

If comprehensive correction improves only the current draft and harms transfer/time efficiency, reject it for the core beginner loop.

## Planning analysis

Compare light planning support where relevant:

```text
no explicit planner
vs
communicative goal + 2–3 idea slots
```

Do not count planner completion as writing evidence.

## Mobile/input analysis

Because typing skill can contaminate writing fluency:
- record device/input method;
- separate language errors from obvious keyboard/autocorrect events when possible;
- do not interpret raw speed without message/language evidence.

## Falsification criteria

The proposed progression is weakened if:
- sentence-controlled practice produces equal or better delayed independent transfer per minute;
- post-draft comparators increase copying but not new-task performance;
- bounded feedback performs no better than wholesale correction;
- AI assistance raises current-text quality but reduces independent transfer or increases support dependence;
- support fading creates persistent failure without later recovery;
- feedback false-positive rates are too high for safe beginner use;
- learners spend substantially more time for no delayed learning gain.

## Adoption rule

Adopt the guided-to-independent progression only if it produces meaningful delayed new-task gains at acceptable time/effort cost.

Use comparator models only where later unsupported writing improves.

Use AI/AWE feedback only at feedback strengths and confidence levels that preserve learner ownership and improve later unsupported performance.

Do not use final-draft polish, number of corrections accepted, or generated word count as primary learning outcomes.
