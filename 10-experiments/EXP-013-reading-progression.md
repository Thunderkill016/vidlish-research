# EXP-013 — From sentence reading to independent connected text

## Primary question

Which early reading policy produces the best **delayed unseen independent connected-text comprehension + fluency per learning minute** for Vietnamese near-A0 learners?

## Population

Vietnamese-speaking Nếp learners near A0/A1 who can read Vietnamese and have enough English lexical/construction prerequisites for the target text set.

Stratify by:

- written vocabulary access;
- listening vocabulary access;
- construction evidence;
- baseline short-text comprehension;
- baseline reading rate at adequate comprehension;
- prior reliance on translation/audio.

## Conditions

### A — sentence-focused practice

```text
matched vocabulary/constructions
→ isolated sentence comprehension / translation / selection tasks
→ no connected microtext practice
```

### B — graded connected microtexts

```text
high-readiness connected text
→ independent first read
→ bounded on-demand gloss
→ sparse gist/detail evidence
→ changed microtext later
```

### C — graded microtexts + fadeable audio

```text
independent first attempt when feasible
→ optional/scheduled reading-while-listening repair
→ reread text-only
→ later unseen text-only probe
```

### D — graded microtexts + easy reading extension

```text
condition B core
→ additional level-matched self/curated easy reading volume
→ light accountability, not quiz after every page
```

Keep targeted instructional time comparable; record additional voluntary/extensive reading time separately.

## Materials

Use multiple text types:

- practical messages/dialogues;
- short descriptions;
- simple narratives;
- simple informational text.

For each text, estimate:

```text
lexical coverage
construction coverage
critical unknowns
length
reference/cohesion demands
topic familiarity
```

Do not rely on a global CEFR label as the only difficulty signal.

## Immediate outcomes

Measure separately:

- written word recognition / lexical access;
- sentence understanding;
- connected-text gist;
- connected-text detail;
- reading time;
- support use;
- rereads;
- subjective effort.

## Primary delayed outcome

After delay, present **unseen connected texts** matched on target readiness, with:

```text
text only
self-paced
no persistent translation
no audio
no prior exposure
```

Measure:

- gist comprehension;
- detail/inference appropriate to stage;
- reading time at adequate comprehension;
- support requested only after first-pass evidence is captured;
- transfer of known vocabulary/constructions into new text.

Primary efficiency metric:

```text
delayed unseen independent connected-reading gain
──────────────────────────────────────────────
learning minutes
```

Report comprehension and fluency separately before any combined metric.

## Audio-fading analysis

For condition C:

```text
assisted improvement
vs
later text-only improvement
```

If performance rises only while audio is present, audio is functioning as support rather than independent reading development.

## Extensive-reading analysis

For condition D, record:

- amount read;
- text difficulty/readiness;
- abandonment;
- voluntary continuation;
- sparse accountability completion;
- delayed independent reading growth.

Do not treat pages/books completed as learning outcomes.

## Fluency-transfer analysis

If repeated reading is used inside B/C/D, compare:

```text
speed/comprehension on practiced text
vs
speed/comprehension on unseen parallel text
```

Faster rereading alone is not sufficient evidence of general reading fluency.

## Strategy-use analysis

If a learner receives a strategy prompt, log:

```text
strategy_type
reason
prompted_or_self_initiated
text_position
later_unprompted_use
```

Do not infer strategy mastery from self-report alone.

## Decision rule

Adopt the connected-text progression if it produces stronger delayed unseen independent reading than sentence-focused practice at acceptable effort/time cost.

Use audio-assisted reading only for learner subgroups/stages where it improves later text-only performance or materially reduces effort without persistent dependence.

Expand extensive easy reading only if added reading volume predicts meaningful delayed reading/language gains rather than completion metrics alone.
