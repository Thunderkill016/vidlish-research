# Initial learning model

The current product hypothesis is a bounded loop:

```text
communicative can-do
→ understandable short input
→ attempt meaning before full reveal
→ notice useful form/sound
→ guided retrieval
→ changed-context use
→ delayed review
→ unseen/parallel probe when appropriate
```

This is a **synthesis and product model**, not the result of one study.

## Evidence dimensions

Every target item may accumulate distinct evidence:

1. `understood`
2. `recalled`
3. `transferred`
4. `retained`

The system must not collapse these into `mastered=true` merely because a learner completed a task.

## Why input comes before broad output for beginners

Near-A0 learners cannot produce language they have never encountered meaningfully. Early output can still exist as repetition, selection, substitution, controlled recall and short guided production. The product should expand freedom as the learner demonstrates comprehension and recall.

## Falsifiable product assumptions

- The loop is understandable to a real near-A0 learner.
- The loop produces measurable delayed retention.
- The changed-context step measures useful transfer rather than puzzle-solving.
- The session remains short enough to return to consistently.

These must be tested with learners.
