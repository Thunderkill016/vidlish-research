# Glossary

- **A0** — informal label used here for a learner below CEFR A1; CEFR itself starts at A1.
- **Can-do** — an observable communicative outcome a learner should be able to perform.
- **Chunk** — a multiword unit learned/used as a meaningful sequence, e.g. “I don't know”.
- **Comprehension** — understanding meaning; not the same as recalling or producing form.
- **Fluency development** — improving speed/ease with largely known language, not merely learning new items quickly.
- **i+1** — shorthand sometimes used for input slightly beyond current knowledge; in this repo it is not treated as a precise measurable law by itself.
- **Intelligibility** — whether speech is understandable to a listener; not equivalence to a native accent.
- **Mediation** — CEFR mode involving creating/relaying meaning between people, texts or contexts.
- **Recall / retrieval** — producing or selecting information from memory with the target answer not fully available.
- **Retention** — successful performance after a delay.
- **Scaffold** — temporary support that helps the learner perform a task and can later be faded.
- **Transfer** — successful use/understanding in a changed or unseen context rather than the exact trained item.
