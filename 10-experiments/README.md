# Experiments

An experiment tests a **product assumption**, not whether a source “is true”.

## Naming

`EXP-###-short-name.md`

## Required fields

- hypothesis;
- linked claims/principles/features;
- target learner;
- treatment/control;
- primary learning outcome;
- secondary engagement outcomes;
- minimum meaningful effect / decision threshold where feasible;
- duration and delayed test window;
- stopping / exclusion rules;
- risks and confounds;
- result;
- decision and knowledge-base updates.

Never optimize a learning experiment solely on completion or click-through.
