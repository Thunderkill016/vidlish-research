# EXP-003 — Does failure diagnosis improve later listening?

## Question

For Vietnamese-speaking near-A0 adults, does a short diagnostic listening loop improve later **audio-only** comprehension and spoken-word recognition enough to justify its extra task time?

## Conditions

### A — comprehension-only

```text
listen
→ meaning question
→ generic feedback / replay
→ continue
```

### B — diagnostic integrated loop

```text
listen
→ meaning question
→ on failure: critical decoding probe
→ targeted sound/form or meaning feedback
→ transcript after evidence capture
→ audio-only retry
```

Keep target items, total initial exposures and content difficulty as comparable as feasible.

## Primary outcomes

After a delay, with answer-bearing text hidden:

- comprehension of unseen parallel utterances;
- spoken-word/chunk recognition inside connected speech;
- transfer to an untrained speaker where feasible.

## Secondary outcomes

- learning time per retained target;
- number of replays;
- transcript dependency;
- learner confusion/frustration;
- rate at which the diagnostic branch predicts the later failure type.

## Diagnostic-validity check

For a subset of failures, administer both a decoding probe and a separate lexical-meaning probe so Nếp can estimate whether the cheap branching procedure is actually distinguishing useful failure classes.

## Decision rule

Adopt the extra diagnostic branch only if it meaningfully improves later unsupported listening or provides learner-state information that improves subsequent task selection at acceptable time cost.

Do not choose B merely because immediate post-feedback accuracy is higher.

## Before running

Pre-register:

- definition of near-A0;
- target/sample selection;
- primary delay interval;
- spelling tolerance if transcription is used;
- speaker variation;
- minimum useful learning gain / prediction gain;
- stopping and exclusion rules.
