# RQ-026 source digest — individual differences, affect and self-regulated learning

**RQ:** Which learner differences materially affect learning/participation, and which adaptations are justified rather than personalization theater?

**Status:** initial meta-foundation evidence digest  
**Date:** 2026-08-27  
**Registry:** `data/sources-rq026.json`, `data/claims-rq026.json`

## 1. Why this RQ matters

A personalized learning product can fail in two opposite ways:

```text
ignore real learner differences
→ avoidable friction / dropout / inaccessible tasks

measure every learner trait
→ overfit labels / pseudoscientific routing / false ceilings
```

RQ-026 asks a stricter question:

> Which variables are consequential enough, valid enough and treatment-relevant enough to justify changing learning conditions?

The key distinction is:

```text
predicts outcome
≠
predicts which treatment is best
```

A variable can correlate with achievement without supplying a valid personalization rule.

## 3. Anxiety is consequential but not a learner identity

SRC-0306 synthesized 97 reports / 105 independent samples / 19,933 learners.

The average association between L2 anxiety and achievement was negative (`r ≈ -.36`). Moderator analyses showed that the relation varies across:

- anxiety type;
- achievement measure;
- educational level;
- target language.

This supports treating anxiety as a meaningful learner variable.

It does **not** support:

```text
anxious learner
→ fixed low-ability profile
```

or:

```text
lower anxiety
→ automatically higher language competence
```

For product purposes, anxiety is better treated as a potentially changing state/constraint whose relationship to task performance can be observed over time.

## 4. Willingness to communicate is not the same as speaking ability

SRC-0307 synthesized 44 independent samples (`N = 12,094`).

The structural model linked WTC with:

- perceived L2 competence;
- motivation;
- anxiety;
- frequency of L2 use.

Perceived competence had the strongest contribution among the three high-evidence predictors, while proficiency and inside/outside-class context moderated relationships.

Product implication:

```text
can speak
≠
willing to speak now
```

Nếp needs both constructs if speaking practice is a target.

A learner who declines an open speaking task may need a lower-social-risk or more bounded task; the event should not be interpreted automatically as speaking failure.

## 5. Self-efficacy is useful but must be calibrated against performance

SRC-0308 included 37 studies / 40 independent samples / 23,050 learners.

Average observed self-efficacy–achievement relation was about `r = .46`, with moderators by language/background/proficiency and measure type.

This is strong enough to care about confidence judgments.

But direction can be reciprocal:

```text
good performance → stronger self-efficacy
strong self-efficacy → more persistence/attempts → performance
```

Therefore Nếp should not manipulate self-efficacy through empty praise.

Candidate product goal:

```text
truthful competence experiences
+
calibrated confidence
```

not merely maximum confidence.

## 6. Motivation is multidimensional

SRC-0309 (SDT meta-analysis) supports positive relations between autonomous motivation and L2 achievement.

SRC-0310 adds a warning: L2 motivational constructs can predict **intended effort** much more strongly than objective achievement, and measurement overlap can inflate some relationships.

This reinforces an existing research rule:

```text
motivation / effort / app return
≠
language evidence
```

Motivation should affect support, goal framing and participation design; it should not directly raise a capability state.

## 7. Self-regulation is teachable

SRC-0311 synthesized 16 studies / 1,780 participants.

SRL interventions improved:

- language achievement;
- strategy use;
- self-efficacy.

The evidence base is not broad enough to define one universal SRL curriculum. It is heavily weighted toward tertiary education and writing.

Still, it rejects a bad personalization story:

```text
learner has poor self-regulation
→ permanently needs external control
```

A better hypothesis is:

```text
planning / monitoring / strategy use
can itself be scaffolded and learned
```

## 8. Aptitude is real; aptitude labeling is dangerous

SRC-0312 synthesized 66 studies, 109 unique samples and 13,035 learners.

It supports language aptitude as a meaningful multidimensional construct. Different components show different predictive relations to outcomes.

SRC-0313 highlights important validity limits:

- traditional aptitude instruments partly reflect historical teaching conditions;
- explicit/formal learning is overrepresented;
- pragmatic and productive learning may be underrepresented;
- predictive validity alone does not prove full construct validity.

SRC-0315 is particularly important for personalization because it includes aptitude–treatment interactions in grammar acquisition.

This provides a proof of principle that:

```text
learner characteristic × treatment
```

can matter.

But it does **not** justify:

```text
one aptitude test
→ one permanent Nếp learning path
```

The evidence is too domain- and treatment-specific.

## 9. Working memory is a moderator, not a destiny score

SRC-0314 synthesized 79 samples / 3,707 participants / 748 effect sizes.

Working memory had a positive but modest association with L2 outcomes (`ρ ≈ .255`). Executive-control and verbal measures showed stronger relations than storage/non-verbal measures.

This is consistent with cognitive-load differences among learners.

But a product inference such as:

```text
low WM score
→ never give complex input
```

is unsupported.

A safer route is to observe actual overload/failure under known task conditions and adapt task/support load reversibly.

## 10. Learning styles fail the personalization test

SRC-0316 specifies the kind of evidence needed to support the popular meshing hypothesis:

```text
classify learner style
×
randomize instructional treatment
→
crossover interaction on common outcome
```

The review found no adequate evidence base for using learning-style assessment in educational practice.

Therefore Nếp should explicitly reject:

- VARK routing;
- “visual learner” curriculum;
- “auditory learner” curriculum;
- personality-style lesson assignment without treatment-interaction evidence.

This does **not** mean modality never matters. Modality matters when the **target construct** requires it: listening must include listening; speaking must include speech.

## 11. Prior literacy and schooling must remain first-class context

SRC-0317 reviews adult L2 emergent readers and shows that low print literacy / limited formal schooling creates different learning demands.

This matters even if the initial Nếp target population is mostly literate Vietnamese adults because the product must not assume:

```text
adult
→ strong L1 literacy
→ familiar with school-like tasks
```

Prior literacy should be represented separately from English capability.

## 12. Neurodiversity: evidence demands restraint

SRC-0318 found only a small recent empirical intervention literature for foreign-language learning among learners with ASD, ADHD and intellectual disability.

The direct evidence is too sparse to derive global neurotype-specific pedagogy.

Therefore Nếp should prefer:

```text
learner-declared access need
+
observable interaction barrier
→ reversible accommodation
```

over:

```text
clickstream pattern
→ inferred ADHD/autism/dyslexia
→ hidden curriculum change
```

## 13. Vietnamese adult directness

### SRC-0319 — Ho Chi Minh City

148 adult learners across five language centers reported patterns including:

- strong motivation / clear goals;
- relatively low self-confidence;
- short study-time investment;
- limited speaking-practice environment.

### SRC-0320 — Da Nang

70 adult EFL learners reported motivation linked to career/job/communication goals alongside:

- time constraints;
- literacy difficulties;
- financial burden.

These studies do not establish national prevalence.

They do support separating:

```text
want to learn
ability to learn
available time
confidence
practice opportunity
financial/access constraint
```

rather than collapsing all of them into `motivation` or `level`.

## 14. Personalization evidence hierarchy

RQ-026 proposes the following **research hierarchy**, not yet a production algorithm:

```text
1. target construct requirement
   e.g. listening requires auditory evidence

2. explicit learner constraint / accessibility need
   e.g. available time, device/audio access

3. repeated observed task state
   e.g. overload, avoidance, support dependence

4. malleable affect/SRL state
   e.g. anxiety, WTC, self-efficacy, strategy use

5. validated cognitive moderator
   e.g. aptitude / working memory
   ONLY where treatment-interaction evidence exists

6. preference / style label
   insufficient alone
```

The deeper rule is:

> Personalization must earn its complexity by improving learner outcomes relative to a simpler policy.

## 15. Candidate adaptation contract

A candidate adaptation should record:

```text
trigger observation
construct targeted
adaptation made
reason / evidence family
expected benefit
cost / trade-off
expiry / recheck rule
outcome after adaptation
```

Default behavior should be reversible.

Example:

```text
repeated speaking avoidance
+
adequate demonstrated bounded oral capability
+
high self-reported task anxiety
→
reduce social/open-endedness temporarily
→
keep actual speech requirement
→
retest willingness and performance later
```

Not:

```text
learner = anxious type
→ permanently easier speaking track
```

## 16. What RQ-026 does not establish

It does not establish:

- a universal anxiety threshold;
- an aptitude cutoff;
- a working-memory-based curriculum;
- a neurotype-specific method;
- a fixed learner persona system;
- that learner preference should override target-skill requirements;
- the exact adaptive algorithm for Vietnamese near-A0 adults.

Those remain validation questions for `EXP-026` and later learner data.
