# EXP-016 — Quality-preserving fluency transfer and retention

## Primary question

Which fluency-consolidation policy produces the best **delayed unsupported changed-task quality-preserving fluency gain per practice minute** for Vietnamese-speaking Nếp learners near A0/A1?

The experiment is designed to distinguish:

```text
getting faster at what was just practiced
```

from:

```text
becoming more efficient with useful English in a new instance after a delay
```

## Core falsifiable hypothesis

A policy that combines bounded repetition, changed-content variation and delayed return will produce more portable fluency than a same-item speed policy, without reducing meaning, comprehension, accuracy or intelligibility.

This is a product hypothesis, not an established universal law.

## Population

Vietnamese-speaking learners near A0/A1 with prerequisite evidence for the target capability.

A target enters deliberate fluency practice only when the learner shows enough evidence that it is already learnable/known rather than unknown.

Candidate readiness evidence:
- target meaning understood;
- spoken/written form recognized as relevant;
- target recalled or produced under moderate support;
- at least one meaningful use or interpretation succeeds;
- error rate is low enough that repetition is unlikely to rehearse a wrong mapping.

Exact thresholds are part of the experiment.

Stratify where feasible by:
- vocabulary/chunk evidence;
- construction evidence;
- baseline listening/speaking/reading evidence;
- baseline response latency or speech timing where reliable;
- prior support dependence;
- device/input modality;
- previous exposure to the task family.

## Experimental policies

### A — Same-item speed policy

Matched practice time.

```text
same prompt/content
→ repeat
→ try to respond/read more quickly
→ repeat
```

Purpose:
- estimate local practice effects;
- expose how much apparent fluency can be produced by familiarity/memorization alone.

No product adoption is implied even if practiced-task speed rises strongly.

### B — Bounded same-task repetition

```text
first meaningful performance
→ brief feedback if required
→ repeat same content a small number of times
→ stop on criterion/plateau
```

Meaning and quality guardrails remain active.

Purpose:
- estimate the value of repetition when it is bounded rather than endless.

### C — Bounded repetition + changed-content variation

```text
first meaningful performance
→ short same-task repetition
→ change lexical slot/content
→ change surface wording
→ changed scenario within the same communicative function
```

Examples:

```text
I'd like coffee.
→ I'd like tea.
→ Can I get a tea?
→ order a drink in another café scenario
```

Purpose:
- test whether procedural familiarity can be preserved while reducing script dependence.

### D — Variation + distributed return

Condition C plus delayed returns.

```text
initial consolidation
→ changed-content probe
→ spaced return
→ different surface realization
→ delayed unseen probe
```

Candidate lag conditions may include shorter and longer intervals, but no interval is treated as universally correct in advance.

## Repetition provenance

For every attempt record at minimum:

```text
exact_item_repetition_count
same_content_repetition_count
same_task_family_count
same_communicative_function_count
same_voice_or_partner_count
support_level
prior_exposure_count
```

Never compare repetition 4 with unseen attempt 1 as though they had equivalent familiarity.

## Shared quality guardrails

A temporal gain is positive only if required quality remains intact.

### Speaking
- communicative meaning achieved;
- target construction/lexis acceptable enough for stage;
- intelligibility preserved;
- major meaning-changing errors not increased.

### Listening
- intended meaning/comprehension correct;
- no transcript/translation before an unsupported probe unless the probe explicitly tests supported performance;
- changed voice/sentence evidence stored separately.

### Reading
- comprehension preserved;
- primary transfer outcome uses unseen parallel text;
- practiced-passage rate is stored only as local performance evidence.

### Interaction
- response is contingent on the preceding turn;
- shared goal progresses;
- learner remains intelligible enough;
- repair is successful when genuinely needed.

### Writing, optional secondary phase
- intended proposition/task fulfilled;
- target construction/lexis appropriate enough;
- typing speed is separated from language-generation latency.

## Speaking task family

Use short practical functions with enough known language:
- identify self/basic information;
- request an item;
- state a preference;
- describe a simple current state;
- ask for clarification;
- report a small problem.

### Same-task measure

Collect:
- articulation/speech rate where sample length permits;
- response initiation latency where interpretable;
- pause frequency/location/duration where valid;
- repair/repetition/reformulation;
- task success and intelligibility.

Do not fabricate temporal precision on samples too short to support it.

### Immediate changed-content probe

Keep function and construction family, change content.

```text
practice: ask for water
probe: ask for a charger
```

### Delayed changed-task probe

After delay:
- new prompt wording;
- new lexical content within readiness;
- no visible model before first attempt;
- no exact memorized answer available.

## Listening automaticity family

The purpose is not to turn listening into a reaction-time game.

Use targets already known declaratively.

Practice candidates:
- sound-to-meaning recognition;
- short contextual appropriateness judgments;
- rapid interpretation of known chunks inside short sentences;
- multiple speakers for known material.

### Listening transfer probe

Use:
- new sentence;
- same known target relation/function;
- changed speaker where feasible;
- normal speech timing appropriate to stage;
- meaning question requiring actual interpretation.

Collect:
- correctness;
- response time only after correctness is established;
- replay/support usage;
- changed-speaker cost;
- delayed comprehension.

A faster target-word judgment with no gain in changed-sentence comprehension is not global listening improvement.

## Reading fluency family

Use short connected texts within lexical/construction readiness.

Practice may include:
- one or two rereads;
- phrase-level grouping support;
- optional audio repair where justified by RQ-013 policy.

Primary transfer measure:

```text
unseen parallel text
+ self-paced reading
+ comprehension
```

Track:
- time/rate;
- comprehension;
- support use;
- repeated-text familiarity;
- delayed unseen-text performance.

## Interaction fluency family

Use bounded goal-driven exchanges.

Example:

```text
Partner: What would you like?
Learner: I'd like a coffee.
Partner: Small or large?
Learner: Small, please.
```

Changed probe:

```text
Partner: What can I get you?
...
```

Collect:
- response latency;
- response contingency;
- goal progression;
- partner rescue;
- repair initiation/success;
- intelligibility.

Do not reward the smallest possible gap. Overlap, premature response or fast irrelevant answers are not successful interactional fluency.

## Chunk flexibility probe

For selected useful chunks:

```text
retrieve exact chunk
→ substitute one slot
→ new lexical content
→ changed scenario
→ interactional use
→ delayed spontaneous retrieval
```

Measure the decline across novelty levels.

A learner who is fast only on the memorized sentence is script-dependent rather than flexibly fluent.

## Time-pressure manipulation

Time pressure is experimental and only available after successful baseline use.

Possible variants:
- no explicit time pressure;
- gentle shrinking preparation time;
- shrinking delivery window for tasks long enough to support it.

Back off immediately if:
- meaning failure increases;
- accuracy meaningfully declines;
- intelligibility falls;
- learner begins guessing;
- interaction contingency deteriorates.

## Repetition stop-rule experiment

Compare candidate stop policies:

### Fixed small count
For example, a low fixed number used only as a comparator.

### Plateau-based
Stop when temporal/effort improvement becomes negligible over recent repetitions while quality is stable.

### Transfer-triggered
Switch to variation once the learner passes a changed-content probe.

### Risk-triggered
Stop when verbatim reuse, quality loss or frustration increases.

The final product should prefer the simplest policy that predicts delayed transfer well.

## Immediate outcomes

Report separately:
- local same-item efficiency gain;
- changed-content efficiency gain;
- meaning/task success;
- accuracy/comprehension/intelligibility;
- support dependence;
- time on task.

Do not collapse these into one fluency percentage.

## Delayed outcomes

At one or more delayed points collect:
- changed-task performance;
- changed-content performance;
- reduced-support performance;
- retention of meaning/accuracy;
- temporal efficiency where measurement is reliable.

Delayed probe timing is itself an experimental parameter and can integrate with RQ-004 review policy.

## Primary outcome

```text
delayed changed/unseen quality-preserving fluency gain
─────────────────────────────────────────────────────
practice minutes
```

Operationalization differs by modality but must always include a quality constraint.

## Secondary outcomes

- immediate local practice gain;
- immediate transfer gain;
- delayed retention;
- support reduction;
- learner-reported effort/confidence;
- frustration/dropout;
- response variability;
- exposure cost;
- partner rescue in interaction.

Engagement measures remain secondary to learning outcomes.

## Local-performance versus learning analysis

For each policy calculate a transfer gap such as:

```text
same-item gain
− changed-task gain
```

A very large gap indicates that the policy mainly improved practiced performance.

Also compare:

```text
immediate changed-task gain
vs
delayed changed-task gain
```

to distinguish temporary facilitation from retained development.

## Speed-quality trade-off analysis

Flag cases such as:

```text
speed ↑
meaning ↓
```

```text
pause frequency ↓
repair errors ↑
```

```text
response latency ↓
contingency ↓
```

A policy is not adopted merely because one temporal dimension improves.

## Personal/L1 timing calibration

If L1 baseline data are ethically and practically collected, use them only as contextual evidence, not as a requirement that all learners imitate native-speaker timing.

At minimum use:
- within-learner change;
- task-matched comparisons;
- the learner's own historical distributions.

Never define mastery as one universal speech rate.

## Measurement audit

Near-A0 responses can be very short, making automated temporal measures unstable.

Audit a stratified sample for:
- speech segmentation accuracy;
- pause detection;
- ASR transcript error;
- syllable/word-count reliability;
- response-onset detection;
- interaction turn-boundary detection;
- comprehension scoring;
- human intelligibility agreement where required.

A metric that is unreliable on target responses is excluded from mastery logic even if it is convenient to compute.

## Falsification criteria

The proposed fluency engine is weakened if:
- practiced-task speed rises but delayed changed-task performance does not;
- temporal gains systematically reduce meaning, accuracy, comprehension or intelligibility;
- variation adds time without improving transfer;
- distributed return adds no delayed value relative to a cheaper policy;
- the learner becomes increasingly dependent on exact scripts;
- target listening judgments become faster but unseen listening comprehension does not improve;
- practiced-passage reading rate improves without unseen-text comprehension/rate benefit;
- interaction latency improves while relevance, goal progress or repair worsens;
- automated metrics are too unreliable on short near-A0 samples;
- one fixed repetition/spacing policy performs poorly for meaningful learner subgroups.

## Adoption rule

Adopt only policies that improve later unsupported changed-task performance per learning minute while preserving task meaning and quality.

The product may use local repetition as a means, but it must never label local practiced speed as mastery.
