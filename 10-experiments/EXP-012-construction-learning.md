# EXP-012 — How should Nếp teach grammar/constructions?

## Primary question

Which instructional loop produces the strongest **delayed unseen interpretation + production transfer per learning minute** for near-A0 Vietnamese adults?

## Population

Vietnamese-speaking Nếp learners near A0/A1 who have the lexical prerequisites for selected target constructions.

Stratify by:

- baseline listening/reading evidence;
- target vocabulary knowledge;
- prior explicit grammar knowledge;
- support use;
- construction difficulty.

## Target constructions

Use several high-utility constructions rather than one isolated grammar rule. Candidate examples:

```text
I want + NOUN
I can + VERB
Do you + VERB ...?
Where is + NOUN?
There is + NOUN
```

Final targets must be checked for lexical prerequisites and comparable difficulty. Do not generalize from one construction.

## Conditions

### A — rule-first + controlled drill

```text
brief rule explanation
→ model examples
→ fill/choose/substitute exercises
```

### B — meaning-focused exposure only

```text
multiple meaningful examples
→ comprehension activity
→ no deliberate form–meaning processing requirement
→ no explicit explanation
```

### C — structured form–meaning input + production, no rule explanation

```text
meaningful input
→ interpretation task requiring target form
→ varied exemplars
→ controlled production
→ changed-context use
```

### D — integrated Nếp construction loop

```text
meaningful first attempt
→ structured interpretation
→ brief explanation/contrast when triggered
→ interpretation retry
→ controlled production
→ changed-context use
→ delayed review
```

Keep total learning time as comparable as practicable.

## Immediate measures

Separate:

- rule/metalinguistic recall;
- form recognition;
- form–meaning interpretation;
- controlled production;
- changed-context production;
- learner effort;
- time-on-task.

Do not create one averaged `grammar_score` before analysis.

## Primary delayed test

Use unseen items and scenarios after delay.

### Receptive transfer

```text
new lexical realization
new sentence/context
meaning-focused task
no rule visible
```

Learner must process the target construction to answer correctly.

### Productive transfer

```text
new scenario / picture / interlocutor prompt
no complete model
known vocabulary
```

Score:

- successful communicative function;
- target construction accuracy;
- support required;
- latency/fluency when meaningful.

## Cross-modal transfer

Where feasible, include at least one modality change:

```text
trained partly in listening/reading
→ tested in speaking/writing
```

This is stronger evidence of flexible construction knowledge than repeating the same exercise format.

## Primary metric

```text
weighted delayed unseen interpretation + production transfer gain
──────────────────────────────────────────────────────────────
learning minutes
```

Report receptive and productive components separately as well.

## Secondary metrics

- delayed rule recall;
- immediate accuracy;
- support dependence;
- explanation opens;
- self-repair after feedback;
- session completion;
- subjective effort;
- later spontaneous occurrence when enough natural data exist.

## Key analyses

### Rule-test illusion

Measure whether condition A produces the highest rule score but weaker transfer. If so, this directly demonstrates why Nếp must not equate rule knowledge with usable grammar.

### Explanation value

Compare C vs D to estimate whether a brief explanation adds value beyond structured form–meaning input + production for each construction/learner subgroup.

### Interpretation-production balance

Compare delayed receptive versus productive outcomes to test whether additional production practice is needed before a construction can advance.

### Cue leakage

Audit items for shortcuts. If learners can answer from pictures, temporal adverbs or a content word without processing the target construction, the item is invalid for construction evidence.

## Decision rule

Adopt the integrated construction loop as default only if it improves delayed unseen interpretation and/or productive transfer relative to simpler conditions at an acceptable time/effort cost.

Do not choose a condition because it creates the highest same-session grammar-test score.
