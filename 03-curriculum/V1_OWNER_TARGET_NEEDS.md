# V1 Owner Target-Needs Profile

**Status:** direct owner-specific needs input; `n = 1`; not a population curriculum  
**Purpose:** select the first Nếp validation capability for the owner-first phase  
**Parent:** `NEP_CURRICULUM_CONTRACT_V0.md`  
**Population claim:** none beyond this owner

---

## 1. Why this exists

The first Nếp version is intended to be used by the owner personally before broader release.

That makes the owner a legitimate **first target learner**, but not a representative sample of Vietnamese adults.

Therefore:

```text
owner needs
→ may select owner-first validation capability

owner needs
≠ universal Vietnamese curriculum
```

A broader curriculum still requires the RQ-023 / `EXP-023` target-population needs study.

---

## 2. Directly stated learning priorities

Across the project, the owner has repeatedly prioritized:

- usable real English rather than curriculum completion;
- speaking/communication ability;
- natural listening and understanding;
- high retention rather than short-term quiz success;
- practical learning that can be used daily;
- an easy learner-facing loop rather than dense traditional grammar exercise;
- a flow broadly like `listen → understand → remember → speak → review`;
- AI as assistance/feedback rather than the pedagogical authority.

The owner has also reported that conventional app tasks and grammar-heavy exercises can feel boring, difficult and discouraging.

These are **needs/preferences/constraints**, not evidence that one instructional treatment will be superior.

---

## 3. Immediate owner target-use domains

For the first validation slice, the highest-confidence owner needs are broad rather than occupationally specialized:

```text
understand short spoken English
respond orally
handle non-understanding
build language that remains available later
```

Longer-term target domains can include richer media/content and broader real communication, but they should not be forced into the first near-A0 slice if their language load hides the learning mechanism being validated.

---

## 4. First-slice selection criteria

The first owner capability should:

1. serve a real communicative purpose;
2. matter to a learner who often cannot yet understand continuous English;
3. require both listening and actual speaking so modality integrity can be tested;
4. be achievable with a very small language-resource set;
5. naturally allow Vietnamese support without confusing supported and independent evidence;
6. allow feedback/self-repair;
7. allow meaningful changed-context probes;
8. allow delayed re-probing;
9. not require a large grammar/vocabulary prerequisite inventory;
10. be technically simple enough that pedagogy—not flashy AI—remains the main experiment.

## 5. Candidate capability comparison

| Candidate | Need value | Near-A0 feasibility | Tests listening + speaking | Changed-context probe | First-slice fit |

---

## 6. V1 owner-first decision

Select this first validation capability:

> **When a short spoken message is not understood, the learner can recognize the breakdown and orally request repetition in a way an interlocutor can understand.**

Why this is a strong validation target:

```text
real purpose
+ listening breakdown
+ meaningful form/function
+ actual oral retrieval
+ pronunciation/intelligibility
+ interaction repair
+ support fading
+ changed context
+ delayed retention
```

It exercises many important Nếp Method boundaries while remaining linguistically small.

This decision is **owner-first and provisional**. It does not establish that every Vietnamese beginner should learn this capability first.
