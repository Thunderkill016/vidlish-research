# Evidence handling

## Source hierarchy

Prefer, where appropriate:

1. systematic review / meta-analysis;
2. high-quality handbook / evidence-based guideline;
3. preregistered or well-designed controlled study;
4. replication / converging observational evidence;
5. descriptive or qualitative study;
6. expert argument / theory;
7. product blog / benchmark;
8. anecdote.

Hierarchy does not remove the need to match the source to the question.

## Minimum extraction fields

For empirical studies, record when available:

- population / L1 / age;
- proficiency;
- sample size;
- task/intervention;
- comparison;
- duration;
- immediate outcome;
- delayed outcome;
- transfer outcome;
- effect direction / uncertainty;
- key limitations;
- relevance to Nếp target learner.

## Citation policy

- Store stable URL/DOI and bibliographic metadata.
- Do not store pirated copies.
- Open-access PDFs may be linked; retain external copyright notices.
- Quote sparingly; summarize findings in our own words.
- If a source cannot be opened/verified, mark it explicitly.
